# Как обновлять подборку

[← Главная](README.md)

1. Откройте Wiki из карточки предмета и проверьте, что это нужные год и поток. При изменении дедлайна сохраните ссылку и точную формулировку объявления.
2. Обновите карточку в `courses/`, сводку в `README.md` и запись в `data/assignments.json`. Измените дату проверки только у действительно перепроверенных данных; общую дату сборки меняйте после проверки всех курсов.
3. Добавляя PDF, сохраните его в `assignments/` без изменения условий. Запишите исходный URL, дату загрузки и SHA-256 в `data/files.json` (`shasum -a 256 assignments/имя.pdf`).
4. Обновите соответствующую выдержку в `sources/`; не копируйте ведомости с оценками, личные данные, коды регистрации или ссылки, дающие доступ к редактированию.
5. Проверьте относительные ссылки через GitHub Preview и отправьте pull request с описанием изменившегося задания или срока.

Не превращайте «перед следующим семинаром» в дату без подтверждённого расписания. Не заменяйте неизвестное время на 23:59. Рекомендуемый срок и строгий срок храните отдельно. Если год сомнителен, оставьте `date: null`, исходную дату — в `source_text`, статус — `year_unconfirmed`.

Поле `task_count` считает все задачи листка, включая звёздочки. `timezone: null` означает, что пояс не указан источником. `deadlines: []` означает отсутствие опубликованного конкретного срока. Файлы JSON и Markdown редактируются вручную; автоматического обновления с Wiki нет.
