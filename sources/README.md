# Источники и границы проверки

[← Главная](../README.md)

Дата получения: **16.09.2026**. Область: **ПМИ, 1 курс, М++ и П+, 2026/27**.

## Маршрут обхода

1. [Главная Wiki](https://wiki.cs.hse.ru/) → раздел курсов 2026/27 → первый курс ПМИ → М++ и П+ ([выдержка](wiki-index.md)).
2. Прочитаны все четыре существующие страницы в этих двух блоках: [комбинаторика](combinatorics.md), [алгебра](algebra.md), [матанализ](analysis.md), [C++](cpp.md).
3. Из двух листков комбинаторики прочитаны обе страницы; ДЗ 1 и ДЗ 2 находятся на вторых страницах. Прочитан одностраничный PDF ДЗ 1 по алгебре. Файлы скачаны напрямую из Google Drive и Яндекс Диска и сохранены без изменений. [Адреса оригиналов и SHA-256](../data/files.json).
4. Открыта публичная страница [base.cpp](https://base.cpp-hse.net/): доступ к заданиям требует входа. Закрытый курс не проверен.
5. Ссылка на АиСД П+ в каталоге отмечена `redlink=1` и «страница не существует». Это означает отсутствие страницы на момент получения каталога, а не отсутствие дисциплины.

## Как получены страницы

Прямые HTTP-запросы к wiki.cs.hse.ru из среды сборки завершались обрывом соединения. Текст страниц получен через **Jina Reader** (`https://r.jina.ai/` + URL источника). Это промежуточное представление сайта, которое может кешироваться; номер ревизии Wiki и время последнего изменения не установлены. Дата проверки — дата получения текста, не гарантия отсутствия более новых правок на сайте.

В этой папке — выбранные выдержки, не полный архив Wiki. Формулировки сроков сохранены. В README добавлены отдельно обозначенные выводы: год из названия курса, принадлежность PDF к домашке и предупреждение о C++.
